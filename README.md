# 需求文档：Hello NewEra 单页欢迎站

## 一、目标
交付一个可直接打开的单页网站，用于展示「Hello NewEra」标题、一句欢迎文案和一个底部按钮，整体观感干净、克制、有设计感。

## 二、功能清单
1. 页面主标题：文字内容为 **Hello NewEra**。
2. 欢迎文案：标题下方一句简短的欢迎语，说明这个页面的用途。
3. 底部主按钮：位于页面下部居中，点击后产生可见反馈（按钮文案切换为「已欢迎」并进入禁用态），带有 hover / focus / active / disabled 状态。
4. 标题上方一个极简内联 SVG 标识（纯装饰，aria-hidden），用于增强视觉层次。
5. 页面底部版权行：显示年份与站点名。

## 三、页面 / 模块
单页结构，自上而下分为：顶部装饰标识区、主标题区、欢迎文案区、按钮区、版权行。

## 四、布局草图

```
+----------------------------------------------------------+
|                                                          |
|                    ( 极简 SVG 标识 )                     |
|                                                          |
|                                                          |
|                      Hello NewEra                        |
|                   欢迎来到 NewEra                        |
|            一句欢迎文案，简短说明这个页面。              |
|                                                          |
|                                                          |
|                   [ 开始体验 ]  按钮                     |
|                                                          |
|                                                          |
|  -----------------------------------------------       |
|        © 2025 NewEra · Hello NewEra                     |
+----------------------------------------------------------+
```

桌面端为居中单列布局，最大内容宽度 720px；移动端（<= 480px）缩小字号与内边距，保证不出现横向滚动。

## 五、交互流程
1. 用户打开页面 → 看到标题、文案与底部按钮，按钮处于可点击状态。
2. 鼠标悬停 / 键盘聚焦按钮 → 背景变亮并轻微上浮，出现聚焦外环。
3. 点击按钮 → 文案切换为「已欢迎」，按钮变为禁用态（降低透明度），页面出现一次淡入的欢迎提示文案。
4. 再次点击无效（disabled）。

## 六、视觉与实现说明
- 配色：深色中性背景（近黑蓝灰）+ 单一主色（青蓝 #4C8DFF），文字使用灰白两级；不使用彩虹色与高饱和渐变。
- 字体：系统字体栈（system-ui / -apple-system / Segoe UI / Roboto 等），不引入外部字体与 CDN。
- 样式：全部写在 `index.html` 的 `<style>` 中，使用 CSS 变量统一颜色、间距、圆角、阴影。
- 脚本：使用 `addEventListener` 绑定按钮事件，不使用内联事件属性，不使用 eval。
- 图标：内联 SVG，无外部图片依赖。

## 七、验收标准
1. 页面主标题显示为「Hello NewEra」，水平居中。
2. 标题下方显示一句完整的欢迎文案。
3. 底部存在一个主按钮，点击后有可见反馈（文案变化 + 禁用态 + 欢迎提示），不是装饰性元素。
4. 全站仅使用一个主色 + 中性色，无 emoji，无外部资源加载失败。
5. 375px 宽度下无横向滚动，标题与按钮完整可见。
6. 浏览器控制台无 JavaScript 报错。

## 八、约束
- 单页交付，仅一个 HTML 文件，双击即可打开。
- 不使用外部图片、字体或 CDN 资源。
