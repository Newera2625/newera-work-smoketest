# 需求文档：Hello NewEra 单页网站

## 1. 目标
交付一个结构极简、视觉精致的单页落地页，向访客问候并提供一个明确的下一步动作（底部按钮）。

## 2. 功能清单
1. **主标题**：页面视觉中心显示「Hello NewEra」。
2. **欢迎文案**：标题下方一句简短欢迎语。
3. **底部按钮**：页面底部一个主色按钮，点击后给出可见反馈（欢迎提示条），可再次点击/重置回到初始状态。
4. **背景层次**：使用纯 CSS 绘制的柔和光晕渐变背景，不依赖任何外部图片资源。
5. **响应式**：手机（375px）与桌面（1440px）均完整显示，无横向滚动。

## 3. 页面结构（单页，仅一个页面）

页面布局草图（桌面端，移动端上下堆叠比例一致）：

```
+----------------------------------------------------------+
|  顶部留白（呼吸区）                                        |
|                                                          |
|                    Hello NewEra                          |
|              （超大字重标题，居中）                        |
|                                                          |
|         欢迎来到 NewEra，这里是你的下一个开始。            |
|              （副文案，次级灰度）                         |
|                                                          |
|  +--------------------------------------------------+    |
|  |  反馈提示区：按钮点击后显示“欢迎！”信息条（默认隐藏）|    |
|  +--------------------------------------------------+    |
|                                                          |
|                                                          |
|                                                          |
|  +--------------------------------------------------+    |
|  |              [ 开始探索 ]  主色实心按钮             |    |
|  +--------------------------------------------------+    |
|                                                          |
|  底部页脚：© 2025 NewEra · Made with care              |
+----------------------------------------------------------+
```

移动端（375px）：

```
+----------------------+

|  欢迎来到 NewEra，    |
|  这里是你的下一个开始。|
|                      |

|                      |
|   [ 开始探索 ]       |
|                      |
|  © 2025 NewEra       |
+----------------------+
```

## 4. 交互流程
1. 用户打开页面 → 看到标题、欢迎文案、底部按钮，背景光晕缓慢呼吸动效。
2. 标题与文案入场时轻微上浮淡入（一次性）。
3. 用户点击「开始探索」→ 按钮进入 loading 态（约 400ms，按钮禁用）→ 提示条从下方淡入显示欢迎信息 → 按钮文案变为「重新开始」。
4. 用户再次点击「重新开始」→ 提示条隐藏，按钮恢复初始文案与可用状态。

## 5. 设计规范
- **主色**：深墨蓝 `#1B2A4A`（含深/浅变体用于渐变与 hover）。
- **中性色**：白 `#FFFFFF`、纸灰 `#F5F6F8`、正文灰 `#6B7280`、分隔线 `#E5E7EB`。
- **字体**：系统字体栈（`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", sans-serif`）。
- **间距 / 圆角 / 阴影**：统一使用 CSS 变量；按钮圆角 999px（胶囊），卡片圆角 14px。
- **状态**：按钮具备 hover（主色加深）、focus（可见外轮廓）、active（轻微下压）、disabled（降低不透明度、禁用光标）。
- 图标使用内联 SVG，全站不使用任何 emoji。

## 6. 验收标准
1. 标题显示为 “Hello NewEra”，位于页面主视觉中心，字号显著大于其他文本。
2. 标题下方存在一句明确表达欢迎含义的文案。
3. 页面底部有一个主色按钮「开始探索」，宽度自适应、点击区域完整。
4. 点击按钮后出现可见反馈提示，按钮状态与文案随之变化，可重置。
5. 配色仅一个主色 + 中性黑白灰，无高饱和彩虹色。
6. 控制台无报错，CSS/JS 均为本地文件，无外链资源依赖。
7. 375px 与 1440px 下无横向滚动，文字不溢出，按钮完整可见。
8. 代码中无 TODO、占位符、空函数与 emoji。

## 7. 交付文件
- `index.html`：语义化页面结构。
- `style.css`：全部样式与响应式规则。
- `script.js`：按钮交互逻辑。
