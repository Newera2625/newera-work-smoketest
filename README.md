# Hello NewEra 单页网站 需求文档

## 目标
制作一个简洁的单页网站，聚焦三件事：一个醒目的标题、一句欢迎文案、一个底部行动按钮。整体视觉克制、现代，具有完整的 hover / focus / active 状态，并同时适配桌面与手机。

## 功能清单
1. 顶部品牌区（header）：左侧小型标识（内联 SVG 圆点标记 + 文字 NewEra），右侧为锚点导航（首页 / 关于 / 联系，均为页面内锚点）。
2. 首屏（main / hero）：
   - 主标题：`Hello NewEra`
   - 副标题（欢迎文案）：一句简短欢迎语，说明这里是开始新旅程的地方。
   - 底部主按钮：`开始探索`，点击后在按钮下方出现一条反馈提示文本。
3. 信息区（section）：三张小卡片，分别介绍“快速上手 / 简洁专注 / 响应式”，使用图标 + 短文案。
4. 页脚（footer）：版权信息与联系方式文字。

## 交互流程
1. 用户打开页面，默认停留在首屏，标题与按钮同时可见（桌面首屏高度自适应，移动端正常纵向滚动）。
2. 鼠标悬停主按钮：背景加深、轻微上浮 2px、阴影加深。
3. 键盘 Tab 聚焦主按钮：出现清晰的 focus-visible 外描边；回车/空格触发。
4. 点击按钮：按钮下方淡入一条提示文案（如“已为你准备好接下来的内容。”），再次点击可收起/切换显示。
5. 顶部导航锚点点击后平滑滚动到对应区块。

## 视觉规范
- 配色：单一主色为靛蓝（#4f46e5 及深浅变体），中性色为深蓝灰背景 (#0f1220) 与浅灰文字 (#e7e9f3 / #9aa1b8)，仅此三色系，无彩虹渐变。
- 字体：系统字体栈；主标题使用 clamp() 流体字号（最大约 64px，字重 700，字间距收紧）。
- 间距 / 圆角 / 阴影全部定义在 `:root` 的 CSS 变量中，全站复用。
- 图标全部使用内联 SVG，线宽统一 1.5，禁止 emoji。

## 技术实现说明
- 纯静态多文件结构：`index.html` + `style.css` + `app.js`。
- 事件全部通过 `addEventListener` 绑定，无内联 onclick；无 eval / document.write。
- 语义化标签：header / nav / main / section / footer，图标 SVG 带 `aria-hidden`，按钮为 `<button>`。

## 约束
- 仅需按需求实现标题、欢迎文案与底部按钮三项核心内容，其余区块服务于视觉完整度。
- 页面不得出现 emoji、占位文案或无响应式处理的元素。

## 验收标准
1. 页面 h1 与浏览器标签标题均为 “Hello NewEra”。
2. 首屏居中显示一句欢迎文案，文案下方有一个主按钮。
3. 按钮具备 hover / focus-visible / active 状态，键盘可聚焦并触发。
4. 点击按钮后，按钮下方出现一条反馈提示文本。
5. 桌面与移动端均无横向滚动，标题与按钮不溢出视口。
6. 控制台无报错，无 404 资源，无破图。
7. 全站无 emoji，图标均为内联 SVG。
